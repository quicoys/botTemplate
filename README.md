# bot template
This is a quicbot template, that you can use to create a (chat)bot for Minecraft


----------------------------------
Steps to run it!

1. Install NodeJS

2.  Install required packages (eg. mineflayer with `npm install mineflayer`)

3.  Create a new directory

4.  Create a file with the JavaScript (.js) file extension. You can call it something like: "`bot.js`"

5.  Make sure you are in the correct directory when you try to run the bot!

6.  Run it by in the terminal, which is in the correct dir, executing `node FileName.js` (`node bot.js`) 

7.  Now, it should be up and running shortly. Do not expect it to take more than 10 seconds. Make sure you have the right credentials and host if things aren't working as expected. Questions should get answered here, but https://dsc.gg/quicbot is the official quicbot server where I will probably check more often. Good luck!
